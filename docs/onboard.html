등록 전 점검

등록하면 일어나는 일

  1. 설정 파일 tenants/기업/config.json 이 만들어집니다.
  2. 다음 자동 실행(매일 07:30)에서 키워드 0개의 과거 검색 흐름을 한 번에 받습니다.
  3. 제품과 연결 키워드가 함께 움직인 정도(연결 강도)를 자동 계산합니다.
  4. 슬랙에 아래 "연결 완료" 메시지가 오고, 그날부터 급등 시작·확대·완화·종료 알림이 옵니다.
